# Balonku Ada Lima: pemutar

Iringan lagu anak Balonku Ada Lima untuk bernyanyi bersama, langsung di browser.

- 120 bpm, 4/4, 29 birama, durasi 0:58
- Tombol Melodi flute bisa dimatikan untuk bernyanyi sendiri
- Peta nada dan penggeser posisi bisa diklik untuk loncat ke bagian lain
- Suaranya dari synthesizer yang sudah dirender jadi file audio, bukan rekaman band

## Isi repositori

`index.html` berisi seluruh halaman dalam satu berkas (HTML, CSS, JavaScript, dan audio yang tertanam). Tidak ada proses build.

## Menjalankan

Buka `index.html` di browser, atau lewat GitHub Pages.
